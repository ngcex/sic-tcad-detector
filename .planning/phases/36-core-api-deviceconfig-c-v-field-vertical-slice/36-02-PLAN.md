    Create `etna/api/simulation.py`. Implement `run_cv(config, v_start=0.0, v_stop=-200.0, n_points=40)`:

    1. Build the bias array with `numpy.linspace(v_start, v_stop, n_points)` (conventional reverse-bias convention: 0 down to -200). This is `V_range` for cv_sweep and becomes SimResult.x.
    2. Call `reset_devsim_fully()` first to guarantee a clean session, then `device_info = build_device(config)` (1D path; run_cv targets 1D C-V — if config.half_width_um is set, raise a clear NotImplementedError stating 2D C-V is out of Phase 36 scope, since core cv_sweep operates on the 1D DD device).
    3. Compute area: use `area = config.area_cm2` when passing to cv_sweep so capacitance is returned in Farads for the configured detector area. (Document in a comment that the design spec labels y as F/cm^2 with area=1.0; we use config.area_cm2 so the value reflects the actual device. LIB-05's gate is only "C decreasing with reverse bias", which holds either way.)
    4. Call `cv_result = cv_sweep(device_info, V_range=bias_array, area=area)`.
    5. Build metadata dict: `{"depletion_widths": cv_result["depletion_widths"], "one_over_C_squared": 1.0 / cv_result["capacitance"]**2, "area_cm2": area}`.
    6. Wrap in `SimResult(config=config, sim_type="cv", x=cv_result["voltages"], y=cv_result["capacitance"], metadata=metadata, mesh=None)`.
    7. In a `finally`, delete the built device (via `devsim.delete_device`) or call `reset_devsim_fully()` again so no device leaks after the function returns.

    Use absolute imports only (`from etna.api.device import build_device`, `from etna.api.results import SimResult`, `from etna.core.cv_analysis import cv_sweep`, `from etna.core.devsim_reset import reset_devsim_fully`). Do NOT `from etna import ...`.
