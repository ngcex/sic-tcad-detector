<objective>
Implement `run_field()` — the field/potential-profile facade at a fixed bias — and populate the `MeshData` geometry-viewer contract from devsim post-build node extraction. This is the novel piece of Phase 36: no existing facade extracts a node-aligned mesh, and `ElectricField` is a devsim EDGE model that must be converted to node-aligned values in the api layer (the geometry viewer, Phase 40, must never call devsim itself). run_field supports both 1D (`y_coords=None`) and 2D devices.

Purpose: LIB-03 — run_field returns a SimResult whose `.mesh` attribute is a populated MeshData with node coordinates and field/doping values extracted from devsim post-build.
Output: `run_field()` in `petringa/api/simulation.py`, re-exported from `petringa`; `tests/test_api_field.py`.
</objective>

    Add `run_field(config, bias_V=-100.0)` to the existing `petringa/api/simulation.py` (do not overwrite run_cv from Plan 02). Steps:

    1. `reset_devsim_fully()`, then `device_info = build_device(config)`.
    2. Ramp the device to `bias_V` using the existing core ramp (drift_diffusion.ramp_bias with the same contact/step convention the core C-V and CCE code uses — reverse bias is applied at the cathode as positive V in devsim; follow how cv_analysis.cv_sweep / ramp_bias handle sign). Do NOT invent a new solve loop; reuse core.
    3. Read node arrays via `devsim.get_node_model_values(device=..., region=..., name=...)`:
       - `x_coords` = node "x" (cm)
       - `y_coords` = node "y" (cm) ONLY when 2D (device_info.get("dimension")==2 or config.half_width_um is not None); else `y_coords=None`
       - node_values["NetDoping"] = node "NetDoping"
       - node_values["Potential"] = node "Potential"
    4. Build node-aligned `node_values["ElectricField"]` (ElectricField is an EDGE model, so it is NOT directly node-length):
       - 1D: get edge field via extract_electric_field(device_info) -> (x_centers[N-1], E_edges[N-1]); map to node-length by numpy interpolation onto the node x array (np.interp(node_x, x_centers, E_edges)); this yields |E| at nodes. Store the magnitude (abs) so it is orientation-independent for the viewer.
       - 2D: reuse the plotting2d.py node-aligned E-magnitude pattern (LinearNDInterpolator on Potential over (x,y) nodes, np.gradient on a regular grid, interpolate E_mag back to nodes, NaN->0). Produce a node-length E array.
       This node-aligned field extraction lives entirely in the api layer using numpy — it introduces NO new devsim physics and keeps the "geometry viewer never calls devsim" invariant (the viewer will consume MeshData only).
    5. Populate `regions`: a single-region list `[{"name": device_info["region_name"], "x_min": float(x_coords.min()), "x_max": float(x_coords.max()), "y_min": (float(y_coords.min()) if y_coords is not None else None), "y_max": (float(y_coords.max()) if y_coords is not None else None)}]`.
    6. Populate `contacts`: `[{"name": "anode", "position": 0.0}, {"name": "cathode", "position": float(device_info["total_length"])}]` (positions in cm along depth; use total_length key from device_info — confirm the key name in the device_info dict and adapt if it differs, e.g. total_depth for 2D).
    7. Assemble `mesh = MeshData(x_coords=x_coords, y_coords=y_coords, node_values={"NetDoping":..., "Potential":..., "ElectricField":...}, regions=regions, contacts=contacts)`.
    8. SimResult: `x` = depth axis in um (x_coords*1e4 for 1D; for 2D use x_coords*1e4 as the primary axis but the mesh carries the full 2D grid), `y` = node ElectricField (V/cm), `sim_type="field"`, `metadata={"bias_V": bias_V, "potential": node Potential, "net_doping": node NetDoping}`, `mesh=mesh`.
    9. `finally`: delete the device / `reset_devsim_fully()` so nothing leaks.

    Absolute imports only; no `from petringa import ...`.
