<threat_model>

## Trust Boundaries

- browser -> Streamlit page (value list): the user enters a comma-separated string; it is parsed to floats, never evaluated as code.
- browser -> Streamlit page (parameter selection): the swept field comes from a curated selectbox, never free text, so `ParametricSweep.param` is always a real DeviceConfig field.

## STRIDE Threat Register

- **T-42-03-T1** — Tampering — arbitrary attribute injection into config via sweep param — _mitigate_: `ParametricSweep` clones via `dataclasses.replace`, which `TypeError`s on unknown fields — no setattr/eval (T-37-03-V5). The curated `SWEEPABLE_FIELDS` selectbox further constrains `param` to vetted numeric fields. Do NOT weaken this; do NOT reintroduce a free-text param input.
- **T-42-03-T2** — Tampering / Elevation — value-list code execution — _mitigate_: the value list is parsed with `float()` per token inside `try/except ValueError`; NEVER `eval`/`exec`. Non-numeric input -> `st.error`, no crash.
- **T-42-03-D1** — Denial of Service (local) — malformed / empty value list crashing the sweep — _mitigate_: `float()` per token in `try/except`; require `len(values) >= 1` before running; empty -> `st.warning`.
- **T-42-03-D2** — Denial of Service (local) — solver non-convergence at deep bias (ramp_bias landmine, STATE.md Phase 39) — _mitigate_: default sim_type `run_cce` (v_stop=-40, inside envelope, truncates gracefully); `run_field` excluded from SIM_FACADES; per-value skip-empty aggregation + top-level `try/except RuntimeError` -> `st.error`. SPIKE-confirmed default (42-01-SPIKE-NOTES.md).
- **T-42-03-SC** — Tampering — npm/pip/cargo installs — _mitigate_: no package installs this phase (RESEARCH Package Legitimacy Audit: zero new packages). Planner must not invent an install task.
