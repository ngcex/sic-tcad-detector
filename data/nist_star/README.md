# NIST PSTAR / ASTAR stopping-power tables (real data)

Downloaded **2026-10-20** from the NIST STAR text interface (M.J. Berger, J.S. Coursey,
M.A. Zucker, J. Chang, *ESTAR, PSTAR and ASTAR: Computer Programs for Calculating
Stopping-Power and Range Tables for Electrons, Protons, and Helium Ions*, NIST,
https://physics.nist.gov/PhysRefData/Star/Text/). Nothing in this directory was typed
by hand or copied from memory.

## Raw responses (`raw/`, unmodified HTTP bodies)

Request: `POST https://physics.nist.gov/cgi-bin/Star/ap_table-t.pl` with form fields
`prog=PSTAR|ASTAR`, `matno=<NNN>`, `ShowDefault=on` (default NIST energy grid:
1 keV to 10 GeV for PSTAR, 1 keV to 1 GeV for ASTAR). Composition pages:
`GET https://physics.nist.gov/cgi-bin/Star/compos.pl?ap-text<NNN>`.

## Derived CSVs (`pstar_<material>.csv`, `astar_<material>.csv`)

Regenerated by `uv run python scripts/build_nist_star_tables.py` (pure re-formatting
of the `<pre>` table, `etna.core.stopping_power.parse_nist_star_html`; a test checks
CSV == parse of the raw file). Columns: `energy_MeV, S_electronic, S_nuclear,
S_total` (MeV cm2/g), `csda_range`, `projected_range` (g/cm2), `detour_factor`.

## SiC is NOT in NIST

4H-SiC is composed in `etna/core/stopping_power.py` by **Bragg additivity**
`(S/rho)_SiC = 0.7004 (S/rho)_Si + 0.2996 (S/rho)_C` (amorphous carbon by default).
This ignores chemical binding/phase effects: typically a few percent for protons above
~1 MeV, up to ~10% near the stopping maximum (protons < ~0.3 MeV, alphas < ~2 MeV).
Graphite instead of amorphous carbon changes SiC stopping by <= 1% above 1 MeV.
A SRIM-2013 or ICRU-73/90 SiC table would be the natural cross-check (not done).
