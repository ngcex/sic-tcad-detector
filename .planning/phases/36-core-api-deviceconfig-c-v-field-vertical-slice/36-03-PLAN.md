<objective>
Implement `run_field()` — the field/potential-profile facade at a fixed bias — and populate the `MeshData` geometry-viewer contract from devsim post-build node extraction. This is the novel piece of Phase 36: no existing facade extracts a node-aligned mesh, and `ElectricField` is a devsim EDGE model that must be converted to node-aligned values in the api layer (the geometry viewer, Phase 40, must never call devsim itself). run_field supports both 1D (`y_coords=None`) and 2D devices.

Purpose: LIB-03 — run_field returns a SimResult whose `.mesh` attribute is a populated MeshData with node coordinates and field/doping values extracted from devsim post-build.
Output: `run_field()` in `etna/api/simulation.py`, re-exported from `etna`; `tests/test_api_field.py`.
</objective>
