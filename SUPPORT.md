# Support

ETNA is maintained by one person on a **best-effort** basis. There is no commercial
support and no guaranteed response time. Most questions should get an answer within a
couple of weeks.

- **Usage questions and physics questions:** open an issue with the "Physics or usage
  question" template. If GitHub Discussions is enabled on the repository, use it for
  open-ended discussion.
- **Bugs:** open an issue with the bug template, including a minimal reproducing script.
- **Data contributions** (measured C-V, SIMS/SRP, I(T), CCE): use the data-contribution
  template and see [docs/DATA_REQUEST_CHECKLIST.md](docs/DATA_REQUEST_CHECKLIST.md).
- **Security issues:** follow [SECURITY.md](SECURITY.md); do not post them publicly.

Before asking, check:

- [docs/USAGE.md](docs/USAGE.md), especially §2 "What to trust", §8 "Validity and limits"
  and §16 "Troubleshooting";
- the [open issues](https://github.com/ngcex/sic-tcad-detector/issues).
